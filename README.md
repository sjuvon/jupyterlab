# README `jupyterlab`

Simple container for JupyterLab.  Uses Docker Compose for everything—build and deployment.  Build-time environment variables route through Compose.

I run this on my personal Mac (silicon) using [Colima](https://colima.run/).  You'll need to configure Colima for everything to play nice, particularly mounts.  Can alternatively run JupyterLab via Python venv, but that's not as fun :)
