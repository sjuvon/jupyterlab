# README `jupyterlab`

Simple container for JupyterLab.  Uses Docker Compose for everything—build and deployment.  Build-time environment variables route through Compose.

I use [Colima](https://colima.run/) to run this on my silicon Mac.  It needs to be configured for everything to play nice, like mounts.  Can alternatively run JupyterLab in a Python venv, but that's not as fun :)
